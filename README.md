# 채원이 첫 돌잔치 QUIZ GAME

딸 채원이의 첫 돌잔치에서 하객 퀴즈를 진행하기 위한 발표 자료입니다.
PowerPoint 대신 **HTML 파일 하나**로 만들었습니다.

## 바로 쓰는 법

**PC** — `index.html` 을 브라우저로 열고 **`F` 키로 전체화면**으로 만든 뒤, `→` 키로 넘깁니다.

**휴대폰** — 파일을 직접 열면 안 됩니다(iOS는 로컬 HTML의 JavaScript를 막습니다).
GitHub Pages 주소로 접속한 뒤 **화면을 가로로 돌려서** 보세요.

- 폰트까지 파일 안에 들어 있어 **인터넷 없이도 100% 동일하게** 보입니다
- 서버나 설치가 필요 없습니다
- 총 25장 (표지 · 인사말 · 게임 규칙 · 게임 시작 · QUIZ 01~10 문제와 정답)

## 조작

| 키 | 동작 |
|---|---|
| `→` `Space` `Enter` `PageDown` | 다음 |
| `←` `PageUp` | 이전 |
| `F` | 전체화면 |
| `T` | 3초 카운트다운 |
| `O` | 목차 (원하는 슬라이드로 점프) |
| `M` | 음소거 |

프레젠터 리모컨도 그대로 작동합니다.
휴대폰에서는 화면 오른쪽을 탭하거나 옆으로 쓸어서 넘깁니다.

## 만든 방식

배경의 구름·코인·하트·나무·보물상자는 이미지가 아니라 **인라인 픽셀 SVG**로 그렸고,
8비트 효과음은 음원 파일 없이 **WebAudio로 생성**합니다. 그래서 문구를 언제든 텍스트로
고칠 수 있고, 어떤 해상도의 프로젝터에서도 깨지지 않습니다.

## 수정하려면

`index.html` 은 자동 생성물입니다. **직접 고치지 마세요.**
`_source/slides.src.html` 의 `SLIDES` 배열을 고친 뒤 다시 빌드합니다.

자세한 내용, 남은 할 일, 빌드 방법은 **[WBS.md](WBS.md)** 에 정리되어 있습니다.
